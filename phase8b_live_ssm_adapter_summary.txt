Exact SSM execution flow:
1. Validate incident category is monitoring_agent_failure.
2. Validate recommended action is restart_node_exporter.
3. Validate strict human approval (approved=True) and approver details.
4. Validate target instance ID is explicit and matches the incident's affected resource.
5. Build a fixed SSM payload with:
   - DocumentName = AWS-RunShellScript
   - InstanceIds = [target_instance_id]
   - Parameters.commands = [
       "systemctl restart node_exporter",
       "systemctl is-active --quiet node_exporter"
     ]
   - TimeoutSeconds = 60
   - MaxConcurrency = 1
   - MaxErrors = 0
6. Submit via boto3.client('ssm').send_command().
7. Poll get_command_invocation() for completion with a bounded wait window.
8. Return structured result containing status, exit code, stdout/stderr excerpts, and metadata.
