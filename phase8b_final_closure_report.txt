7. SAFETY IMPROVEMENTS
--------------------------------------------------------------------------------
- Strict Fail-Closed Logic: Any condition failing validation (unallowlisted action,
  category mismatch, target ID mismatch or ambiguity, missing human approval)
  returns status: blocked with executed: False.
- Command Injection Prevention: The adapter enforces a fixed internal payload
  (systemctl restart node_exporter and systemctl is-active --quiet node_exporter).
  Any user-supplied command strings are rejected.
- Dry-Run by Default: CLI and core execution functions default to dry_run=True.
  Live execution requires explicit instantiation of the live adapter.
- Zero Blind Retries: Failed executions or timed-out commands do not trigger
  automated retries; they fail closed and escalate to human operators.
- Verification Gated Closure: close_incident_if_verified() requires all 5 core health
  criteria to be met before permitting incident resolution.
